# Open Source Fonts

Open-source fonts used by **ScrewIt Studio** in its applications and projects.

This repository keeps a central record of the open-source fonts we use, their licenses, attribution information, and official project sources.

## Fonts

### Inter

**Inter** is a typeface designed by Rasmus Andersson, with a focus on readability on computer screens.

* **License:** SIL Open Font License 1.1
* **Author:** Rasmus Andersson
* **Official project:** https://github.com/rsms/inter
* **Website:** https://rsms.me/inter/

Inter is used by ScrewIt Studio for interface and Latin-script text where appropriate.

### Noto Sans Devanagari

**Noto Sans Devanagari** is part of Google's Noto font family and provides support for Devanagari-script text.

* **License:** SIL Open Font License 1.1
* **Project:** Noto Fonts
* **Official project:** https://github.com/notofonts/devanagari

It is used by ScrewIt Studio for Hindi and other Devanagari-script content where appropriate.

## Why this repository exists

ScrewIt Studio may use the same open-source fonts across multiple applications.

Keeping the font information in a separate repository makes it easier to:

* keep license information organized
* provide proper attribution
* identify the original font projects
* reuse the same font information across applications
* keep application-specific legal pages separate from general open-source resources
